# Home overrides

- Pattern: Trust + Conversion (asymmetric hero → categories → offers → products → blog → trust strip)
- Hero: slider + side banners (not centered marketing hero)
- Latest blog: up to 3 published posts via `home_blog_posts`
- Soft UI Evolution shadows on product/blog cards
- Discount strip: brand teal gradient (never neon pink/purple)
- Category chips: min 44px touch, ≥8px gaps
- Trust strip: 2×2 mobile / 4-col desktop — real assurances only, no fake metrics
- Mid banners: prefer 2 asymmetric tiles over equal 3-card row
