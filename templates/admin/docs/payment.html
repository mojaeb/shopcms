{# ── تنظیمات زرین‌پال ────────────────────────────────────────────── #}

تنظیمات زرین‌پال

{
  "merchant_id": "YOUR-MERCHANT-ID",
  "sandbox": true,
  "api_base": "",
  "start_pay_url": "",
  "graphql_url": "",
  "access_token": ""
}
  • sandbox: true — پرداخت آزمایشی (پول واقعی کسر نمی‌شود)
  • api_base / start_pay_url / graphql_url — اگر خالی باشند، endpoint رسمی زرین‌پال استفاده می‌شود
  • access_token — فقط برای refund GraphQL لازم است (از پنل زرین‌پال دریافت کنید)
{# ── Callback URL ────────────────────────────────────────────────── #}

آدرس Callback

پس از پرداخت، کاربر به این آدرس برمی‌گردد. دامنه فروشگاه باید عمومی و HTTPS باشد:

https://your-store.com/api/v1/payments/callback/{gateway}/

در تنظیمات زرین‌پال پنل، آدرس Callback را دقیقاً روی همین URL ست کنید.

استعلام و تطبیق تراکنش‌های معلق

اگر کاربر پرداخت کرد اما به سایت برنگشت (قطع اینترنت، مرورگر بسته شد)، تراکنش در حالت REDIRECTED می‌ماند. Management command زیر تراکنش‌های قدیمی را بررسی و تایید می‌کند:

python manage.py reconcile_pending_payments [--hours 24] [--dry-run]
