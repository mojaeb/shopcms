تنظیم مختصات مبدا فروشگاه

در فرم فروشگاه (تب «ارسال» یا اطلاعات اصلی) دو فیلد عرض جغرافیایی مبدا و طول جغرافیایی مبدا را پر کنید. این مختصات برای محاسبه فاصله واقعی تا آدرس مشتری (در حالت‌های distance و distance_weight) استفاده می‌شود.

  • از Google Maps یا نشان‌مپ مختصات انبار / مرکز ارسال را بردارید
  • فرمت: اعشار (مثال: 35.689200، 51.389000)
  • محدوده معتبر ایران: عرض ۲۵.۰۸ تا ۳۹.۷۸ — طول ۴۴.۰۳ تا ۶۳.۳۲
  • اگر این فیلدها خالی باشند، سیستم به رفتار قبلی (zone_tier بر اساس شهر) fallback می‌کند
{# ── نحوه کار محاسبه فاصله ──────────────────────────────────────── #}

نحوه محاسبه فاصله

روش شرط فعال‌شدن دقت
Haversine (خط مستقیم) مختصات مبدا + مقصد موجود، بدون routing_api_key ±۵٪ کافی برای تعرفه‌بندی
Routing API (مسیر واقعی) routing_api_key در تنظیمات shipping.map فاصله جاده‌ای
zone_tier (شهر/استان) مختصات موجود نباشد گروه‌بندی استانی

نتیجه ۳۰ روز cache می‌شود — برای به‌روزرسانی، cache فروشگاه را از پنل مدیریت پاک کنید.

{# ── تنظیم routing API ───────────────────────────────────────────── #}

تنظیم Routing API (اختیاری)

برای فاصله جاده‌ای واقعی، کلید routing_api_key را در تنظیمات پیشرفته فروشگاه (گروه shipping) قرار دهید: 

{
  "map": {
    "routing_api_key": "YOUR-API-KEY"
  }
}

اگر کلید خالی باشد یا API خطا بدهد، سیستم به Haversine fallback می‌کند و محاسبه شیپینگ fail نمی‌شود.

{# ── GPS چک‌اوت ──────────────────────────────────────────────────── #}

ویجت GPS در چک‌اوت (تم default)

در تم default دکمه «📍 دریافت موقعیت من از GPS» به فرم آدرس اضافه شده:

  • از navigator.geolocation.getCurrentPosition استفاده می‌کند
  • مختصات در دو فیلد hidden latitude / longitude ست می‌شود
  • پیش‌نمایش فاصله از مبدا فروشگاه نمایش می‌دهد (endpoint زیر)
  • مختصات خارج از ایران رد می‌شوند (اعتبارسنجی در API)
{# ── API endpoint ها ─────────────────────────────────────────────── #}

API Endpoints

POST /api/v1/shipping/distance-preview/

پیش‌نمایش فاصله قبل از ثبت آدرس (بدون نیاز به login):

Request:  {"latitude": 36.2972, "longitude": 59.6067}
Response: {"distance_km": "741.234"}

POST /api/v1/addresses/

ثبت آدرس با مختصات (اختیاری):

{
  "full_name": "...", "phone": "...", "province": "...",
  "city": "...", "postal_code": "...", "address_line": "...",
  "latitude": 36.2972,
  "longitude": 59.6067
}
