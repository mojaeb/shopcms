{# ── تب ارسال فروشگاه ───────────────────────────────────────────── #}

تب «ارسال» فروشگاه

  • استان/شهر مبدا — برای محاسبه zone_tier (هم‌استان / مجاور / دورافتاده)
  • وزن بسته‌بندی (base_package_weight_kg) — به وزن محاسبه‌شده اضافه می‌شود
  • آستانه ارسال رایگان — برای کل فروشگاه (مستقل از هر روش)
  • ارائه‌دهندگان فعال — فهرست پرووایدرهای قابل انتخاب برای این فروشگاه
{# ── تعرفه منطقه‌ای zone_tier ───────────────────────────────────── #}

تعرفه منطقه‌ای (zone_tier)

در هر ردیف «تعرفه ارسال» فیلد zone_tier را ست کنید و to_city را خالی بگذارید:

مقدار zone_tier معنا
sameهم‌استان مبدا
adjacentاستان مجاور
farدورافتاده (پیش‌فرض اگر همسایه نباشد)

ردیف شهر به شهر (from_city + to_city) همیشه اولویت بالاتر از zone_tier دارد.

{# ── کلیدهای config روش ارسال ────────────────────────────────────── #}

کلیدهای config روش ارسال

کلید پروایدر توضیح
fixed_priceهمهقیمت ثابت (fallback)
extra_cost_flatهمههزینه ثابت اضافه (تومان)
extra_cost_percentهمهدرصد هزینه اضافه روی تعرفه نهایی
max_weight_kgپستسقف وزن — سبد سنگین‌تر این روش را نمی‌بیند
delivery_citiesپیکلیست شهرهای پوشش پیک؛ خالی = همه شهرها
base_weight_kgdistance_weightوزن پایه برای محاسبه مازاد کیلو (پیش‌فرض ۱ کیلو)
fallback_priceAPIقیمت fallback تا اتصال API خارجی

payment_type: prepaid (پیش‌کرایه) یا postpaid (پس‌کرایه) — روی خود روش ارسال، نه در config.

{# ── Bulk import/export API ──────────────────────────────────────── #}

import/export گروهی تعرفه (API)

به‌جای ویرایش یک‌به‌یک ردیف‌ها، می‌توانید تمام جدول تعرفه را با یک درخواست جایگزین کنید:

GET /api/v1/store-admin/shipping/methods/{id}/prices/export

خروجی JSON آماده‌ی ویرایش و re-upload.

POST /api/v1/store-admin/shipping/methods/{id}/prices/bulk

replace_all: true → کل جدول پاک و جایگزین می‌شود.
replace_all: false (پیش‌فرض) → upsert بر اساس کلید (from_city + to_city + zone_tier + weight_min_kg).
اگر weight_min ≥ weight_max باشد ۴۰۰ برمی‌گرداند. هم‌پوشانی بازه وزنی در warnings هشدار می‌دهد اما رد نمی‌کند. 

{
  "replace_all": true,
  "rows": [
    {"from_city": "مشهد", "to_city": "تهران", "zone_tier": "", "weight_min_kg": 0, "weight_max_kg": 5, "price": 120000, "extra_per_kg": 0},
    {"from_city": "", "to_city": "", "zone_tier": "same", "weight_min_kg": 0, "price": 60000}
  ]
}

لیست استان‌ها برای فرم select: GET /api/v1/store-admin/shipping/locations
