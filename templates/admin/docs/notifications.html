پیامک وضعیت مرسوله

هر بار وضعیت مرسوله تغییر می‌کند، اگر قابلیت فعال باشد یک پیامک به مشتری ارسال می‌شود. برای فعال‌کردن، کلید زیر را در StoreSetting گروه notifications ست کنید: 

key: shipment_sms_enabled
value: true

پیش‌فرض False است — چون ارسال پیامک هزینه دارد و باید صریحاً فعال شود.

وضعیت مرسوله متن پیامک
shipped «سفارش ORD-XXXX شما ارسال شد. کد رهگیری: [کد یا به‌زودی]»
delivered «سفارش ORD-XXXX شما تحویل داده شد. متشکریم!»
  • شماره گیرنده: ابتدا از snapshot آدرس سفارش خوانده می‌شود، سپس از user.phone
  • اگر ارسال پیامک fail شود (اعتبار تمام، شماره نامعتبر و…) سفارش fail نمی‌شود — فقط لاگ می‌شود
  • پیامک تکراری نمی‌رود — اگر وضعیت تغییر نکرده باشد (مثلاً فقط tracking code آپدیت شود) پیامک ارسال نمی‌شود
{# ── کانال SMS ───────────────────────────────────────────────────── #}

تنظیم کانال SMS فروشگاه

کانال‌های اعلان از مدل NotificationChannel در پنل ادمین مدیریت می‌شوند. اگر کانال SMS فعال تعریف نشده باشد، سیستم از پروایدر console_sms (چاپ در ترمینال) استفاده می‌کند.

  • از پنل ادمین → NotificationChannel یک کانال با نوع sms بسازید
  • Provider مناسب (kavenegar، melipayamak و…) را انتخاب کنید
  • config مربوط (api_key و…) را پر کنید
  • is_default: true → برای همه پیامک‌های فروشگاه استفاده می‌شود
{# ── لاگ اعلان‌ها ─────────────────────────────────────────────────── #}

لاگ اعلان‌ها

هر اعلان ارسال‌شده در مدل NotificationLog ذخیره می‌شود با وضعیت‌های sent یا failed.

GET /api/v1/store-admin/notifications/logs/?channel_type=sms
